# Artifacts

Use this folder for durable cloud/devops artifacts promoted when a run is explicitly finished. Drafts stay under the active run until then.

Only documents that others need after a run belong here, and only when the process declares the promotion or the user approves it. Everything else stays in the run, which archiving keeps whole.

Common folders:

- `plans/`
- `reviews/`
- `validations/`
- `handoffs/`
- `maps/`
- `change-packets/`
- `incident-notes/`
- `decisions/`
