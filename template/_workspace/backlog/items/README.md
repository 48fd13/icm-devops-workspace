# Backlog Items

Deferred follow-ups, risks, TODOs, and unresolved questions. Use one Markdown file per item.

Name items:

```text
YYYY-MM-DD-short-slug.md
```

Copy `item-template.md` when creating a new item.

An item's presence here means it is open; there is no status field and no done folder. Resolving an item removes the file. When the work happened in a run, the run is the record. Before deleting the item, promote anything others will need, with the user's approval.
